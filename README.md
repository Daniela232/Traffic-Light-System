# Traffic Light System

A Python traffic-light simulation project demonstrating state transitions, program control flow, and a visual implementation using Pygame.

## Project Overview

This repository contains two implementations of a traffic light system:

- `traffic_light_system.py` — core traffic-light simulation logic.
- `traffic_light_pygame.py` — graphical implementation using Pygame.

## Skills Demonstrated

- Python programming
- State-based logic
- Conditional control flow
- Event-driven programming
- Pygame / graphical interfaces

## Running the Project

Install Python 3 and Pygame, then run the desired script.

```bash
pip install pygame
python traffic_light_pygame.py
```

The non-graphical version can be run with:

```bash
python traffic_light_system.py
```
